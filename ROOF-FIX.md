# Roof geometry history

The previous Facade Revision 3 release removed an invalid out-of-contour OTS cutout that broke roof triangulation. That release used superseded floor plans.

The current `2026-10-05-final-plans-r3` geometry is rebuilt exclusively from the two client-confirmed final plans. It retains hole-containment validation, covers the client-confirmed Store-side roof strip and leaves only the actual OTS plus the deliberate stair-access opening in the roof. See FINAL-PLANS.md and VALIDATION.md for the current geometry and checks.
